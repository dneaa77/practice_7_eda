
# Практическая работа №7

## Тема
Настройка гиперпараметров случайного леса и анализ важности признаков.

## Датасет
Wine Quality — данные о физико-химических характеристиках красного вина.

Источник: https://archive.ics.uci.edu/dataset/186/wine+quality

## Цель
Подобрать гиперпараметры случайного леса с помощью кросс-валидации, сравнить настроенную модель с моделью по умолчанию и исследовать влияние удаления наименее важных признаков.

## Методы
- RandomForestClassifier
- GridSearchCV
- StratifiedKFold
- Accuracy
- F1-macro
- Feature Importance
